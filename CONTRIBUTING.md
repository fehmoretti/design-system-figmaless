# Como contribuir

1. Abra uma issue ou proposta para mudanças relevantes.
2. Crie uma branch curta a partir de `main`.
3. Atualize implementação, testes e Markdown relacionado.
4. Verifique links, acessibilidade e compatibilidade.
5. Abra um pull request com impacto, evidências e plano de migração.
6. Após aprovação, faça merge e sincronize o zeroheight.

Use Conventional Commits: `feat:`, `fix:`, `docs:`, `refactor:`, `test:` e `chore:`.

## Pull request

Inclua: problema, solução, escopo, mudanças visuais, acessibilidade, breaking changes, testes e documentação atualizada.
