# Visão geral

O Design System Figmaless é um sistema **code-first** para equipes que desenham diretamente no navegador. Mantine fornece os primitivos React; os tokens e componentes deste projeto definem a identidade, os contratos de UX e a documentação.

## Princípios arquiteturais

- **Código como fonte de verdade:** decisões aprovadas vivem em tokens, tema e componentes versionados.
- **Composição:** estender Mantine antes de criar APIs paralelas.
- **Semântica:** consumir tokens por intenção, não por valor bruto.
- **Acessibilidade:** WCAG 2.2 AA é requisito de aceite.
- **Documentação junto da mudança:** alteração de API exige alteração do Markdown correspondente.

## Fluxo

Decisão → token → tema Mantine → componente → teste → documentação → release → sincronização com zeroheight.

## Escopo

Inclui fundamentos, componentes, padrões de produto e visualização de dados. Não inclui telas específicas de um produto nem regras particulares de negócio.
