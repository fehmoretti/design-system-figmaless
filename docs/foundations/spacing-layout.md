# Espaçamento e layout

## Unidade base

A escala usa múltiplos de 4 px, exposta por nomes semânticos e compatível com os tamanhos do Mantine.

| Token | Valor |
|---|---:|
| space.0 | 0 |
| space.1 | 4 px |
| space.2 | 8 px |
| space.3 | 12 px |
| space.4 | 16 px |
| space.6 | 24 px |
| space.8 | 32 px |
| space.12 | 48 px |
| space.16 | 64 px |

## Layout

- mobile-first;
- largura máxima de conteúdo definida por contexto;
- grid de 12 colunas para páginas complexas;
- gaps derivam da escala;
- componentes reorganizam antes de comprimir conteúdo crítico.

## Controles

Alturas de referência: XS 32 px, SM 40 px, MD 48 px e LG 56 px. Áreas de toque devem alcançar pelo menos 44 × 44 px quando possível.
