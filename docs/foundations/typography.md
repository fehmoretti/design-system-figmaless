# Tipografia

## Família

**Inter** é a fonte padrão proposta, com fallback para fontes de sistema.

```css
font-family: Inter, ui-sans-serif, system-ui, -apple-system, "Segoe UI", sans-serif;
```

## Pesos

Light 300, Regular 400, Medium 500, Semibold 600 e Bold 700. Prefira Regular para corpo e Semibold para hierarquia; evite Light em textos pequenos.

## Escala semântica

- Display: comunicação editorial de alta ênfase.
- Heading 1–4: estrutura de página.
- Body lg/md/sm: leitura e interface.
- Label: controles e metadados.
- Code: conteúdo monoespaçado.

## Regras

Use no máximo três níveis evidentes por região. Mantenha corpo com line-height entre 1,4 e 1,6. Não use somente tamanho/peso para transmitir estado.
