# Navegação e apresentação de dados

## Navegação

Tabs alternam visões irmãs sem mudar o nível hierárquico. Breadcrumbs mostram localização, não histórico. Stepper serve a processos sequenciais reais. NavLink representa destinos e deve indicar a página atual.

## Tabelas

Use tabela para comparação precisa. Cabeçalhos são explícitos; números alinham à direita; ações permanecem previsíveis. Ordenação, filtro e paginação comunicam o estado atual.

## Responsividade

Em telas estreitas, priorize colunas, permita rolagem horizontal com indicação ou transforme registros em cartões quando a comparação entre colunas não for essencial.

## Estados

Toda região de dados documenta loading, vazio, erro, sem resultados de filtro e conteúdo parcial.
