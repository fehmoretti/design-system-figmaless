# Componentes

Componentes estendem Mantine com decisões consistentes, tipos públicos e acessibilidade testada.

## Categorias

- **Ações:** Button, ActionIcon, Menu.
- **Entrada:** TextInput, Select, Checkbox, Radio, Switch, Date/Time.
- **Feedback:** Alert, Notification, Progress, Skeleton, Loader.
- **Dados:** Table, DataTable, Pagination, Badge, Tooltip.
- **Navegação:** Tabs, Breadcrumbs, NavLink, Stepper.
- **Overlays:** Modal, Drawer, Popover, Combobox.
- **Estrutura:** Card, Paper, Stack, Group, Grid.

## Contrato mínimo da documentação

Objetivo, quando usar/evitar, anatomia, variantes, propriedades essenciais, estados, conteúdo, comportamento responsivo, acessibilidade e exemplos.

## Status

- **Experimental:** API pode mudar.
- **Beta:** pronta para adoção controlada.
- **Stable:** mudanças incompatíveis exigem versão principal.
- **Deprecated:** substituição e prazo documentados.
